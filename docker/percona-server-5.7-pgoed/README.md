# Percona Server 5.7 PGOed Docker Image

This directory contains a community-maintained Docker image recipe built from a PGOed `mini.tar.zst` produced by this repository. It follows the same layout as [docker/percona-server-8.4-pgoed](../percona-server-8.4-pgoed).

Current default assumptions:

- target server: `Percona Server 5.7.44-57` PGOed build (final CentOS 7 compatible release)
- input binary: `Percona-Server-5.7.44-57-PGOed.Linux.x86_64.centos7.mini.tar.zst`
- base image: `redhat/ubi8-minimal` (EL8 glibc runs the CentOS 7 build; `compat-openssl10` provides the required `libssl.so.10` / `libcrypto.so.10`)
- `jemalloc` preloaded when available

## Prerequisites

1. The `5.7.44-57` release asset is already committed in the repo tree; otherwise download it from GitHub Releases (`5.7.44-57`).
2. Build from the repository root so `COPY ${PS_TARBALL}` works.

Default expected path:

- `artifacts/Percona-Server-5.7.44-57-centos7/Percona-Server-5.7.44-57-PGOed.Linux.x86_64.centos7.mini.tar.zst`

## Build

```bash
docker build -f docker/percona-server-5.7-pgoed/Dockerfile \
  -t ps-5.7.44-57-pgoed \
  -t ps-5.7-pgoed .
```

## Run

```bash
docker run --name ps574457 --rm \
  -e MYSQL_ROOT_PASSWORD=root \
  -p 3306:3306 -p 33060:33060 \
  ps-5.7.44-57-pgoed
```

Basic connectivity check:

```bash
docker exec -it ps574457 mysql -uroot -proot -e "SELECT VERSION();"
```

Expected version:

- `5.7.44-57-pgo`

Enable the X Plugin explicitly if needed (it is not auto-installed by this image):

```bash
docker exec -it ps574457 mysql -uroot -proot \
  -e "INSTALL PLUGIN mysqlx SONAME 'mysqlx.so'; SELECT PLUGIN_NAME, PLUGIN_STATUS FROM INFORMATION_SCHEMA.PLUGINS WHERE PLUGIN_NAME='mysqlx';"
```

## Layout

- config: `/etc/my.cnf` and `/etc/my.cnf.d/*.cnf`
- datadir: `/var/lib/mysql`
- init hooks: `/docker-entrypoint-initdb.d/*.(sh|sql|sql.gz)`

## Notes

- `MYSQL_ONETIME_PASSWORD=1` expires the password of every root account created during initialization, including `root@localhost` and the account selected by `MYSQL_ROOT_HOST`.
- The binary was built on CentOS 7 (glibc 2.17, OpenSSL 1.0.2 sonames). `redhat/ubi8-minimal` runs it via `compat-openssl10`; older glibc binaries are forward-compatible.
- The CentOS 7 `mysql` client is linked against EL7-era `libncurses.so.5` / `libtinfo.so.5` / `libreadline.so.6`. Those three libraries are extracted from CentOS 7 vault RPMs into `/usr/lib64` (without replacing the EL8 ncurses/readline packages).
- `libpluginmecab.so` is shipped, but it is linked against the SCL soname `libmecab.so.rh-mysql57-2`, which is not available in EL8 repos. The MeCab fulltext parser therefore does not load out of the box; symlink a `libmecab.so.2` build to that soname if you need it.
- Percona Server 5.7 has no telemetry component, so no telemetry flag is passed to mysqld.
- `auth_pam.so` / `auth_pam_compat.so` can load because `pam` is installed.
- SSL server certificates are auto-generated by mysqld 5.7 on first start, matching upstream 5.7 behavior.
